PROJECT 02 — UI / UX DESIGN

Final Thesis Administration System

A web-based UI/UX design for managing the final thesis administration process, from title submission and supervision to seminars, assessment, and publication.

Figma UI/UX Web Application Prototyping

PROJECT OVERVIEW

Designing a more organized thesis experience.

This project focuses on the interface design of a web-based system for final thesis administration. The design brings several thesis-related activities into one digital platform.

Role

UI/UX Designer

Tool

Figma

Type

Web Application

THE PROBLEM

One process, many academic activities.

The final thesis process involves several administrative activities. A centralized interface can help organize the information and make each stage easier to navigate.

making the thesis journey easier to navigate.
